# Cybersecurity Writeups (Learning Portfolio)

This repository contains selected writeups from hands-on cybersecurity labs (TryHackMe and PortSwigger).
My focus is on fundamentals, methodology, and clear documentation (not just tools/payloads).

## What you'll find here
- **TryHackMe**: pentesting workflow, recon, network enumeration, privilege escalation
- **PortSwigger Web Security Academy**: OWASP Top 10-focused web vulnerabilities (e.g., SQLi, XSS, access control)

## Writeup style
Each writeup includes:
- Objective & scope (high level)
- Methodology / approach
- Key findings
- What I learned

> Note: I avoid posting sensitive details (e.g., flags, credentials) and focus on the learning process.
